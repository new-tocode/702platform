> 它是从 git 的 21 个注解 tag 与提交历史**反推**出来的阶段骨架，回答「这个平台是一步步
> 长成什么样的」。
>
> 装的是**快照**：每一行描述那一次发布做了什么，此后被改掉的部分不追同步
